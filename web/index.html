    How the ranking works

    Every paper gets a score between 0 and 1, combining two parts with the weights set in config/interests.yaml. Each digest window ends today and reaches window_padding_days further back, so a paper indexed or posted a little earlier still shows up:

    Relevance
    Semantic similarity between the paper's title and abstract and your topic prose, computed locally with a static embedding model. The mean embedding of recent literature is subtracted first, so generic life-science wording does not inflate the match. Scores are squashed onto 0–1.
    Tags
    A topic is shown only when it really matches, so a paper can carry several tags or none. Tags are chosen by raw similarity, while topic weights steer the ranking — a lower-weighted topic is still named when it is the one that fits. The topic name counts towards matching alongside its description, so keep the two about the same subject.
    Impact
    The journal's impact factor from config/journals.json, log-compressed so the gap between IF 2 and IF 10 counts for more than the gap between IF 50 and IF 90. Preprints have no impact factor and take a flat value. Journals missing from the table score lower still.
    Saving
    The star keeps a paper. A saved paper stays in the Saved tab whatever its score, and pruning never deletes it, so starring is how a paper outlives the window it was found in. Search reaches every stored paper, with no relevance floor and no date window.

    Impact factors are hand-curated approximations, not licensed JCR data. Treat them as a prestige prior. Edit the file to correct or extend them, then run bin/loki rescore.

    Topics of interest

    Relevance is measured against these. Describe each one in a sentence or two, the way you would to a colleague — richer wording matches better than keywords.

    Score balance

    Every paper's score mixes how well it matches your topics with how strong its journal is. Slide towards topic match to follow the subject wherever it is published, or towards impact factor to favour the bigger journals. Preprints have no impact factor and take a flat value, so leaning right pushes them down the list.
